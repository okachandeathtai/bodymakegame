# BODYMAKE 12 WEEKS

会社員1年目の新人ボディビル選手を12週間育成する、スマートフォン向けPWAゲームの試作版です。食事・筋力トレーニング・休養・メンタルケアを週ごとに調整し、生活イベントに対応しながら大会を目指します。

## いちばん簡単な起動方法

初回だけ、パソコンに [Node.js](https://nodejs.org/) をインストールしてください。その後、このフォルダをターミナルで開き、次の2行を順番に実行します。

```bash
npm install
npm run dev
```

表示された `http://localhost:5173` をブラウザで開くと遊べます。終了するときはターミナルで `Ctrl + C` を押します。

同じWi-Fi内のスマートフォンから確認したい場合は、次を実行します。

```bash
npm run dev -- --host
```

表示された `Network` のURLをスマートフォンで開いてください。PWAのホーム画面追加とService Workerは、安全な接続（HTTPS）または `localhost` で利用できます。

## 製品版相当の確認

```bash
npm run build
npm run preview
```

ビルド成果物は `dist/` に作られます。自動テストは次で実行できます。

```bash
npm test
```

## 遊び方

1. 選手名・性格・出場カテゴリを選びます。
2. 毎週、食事・筋トレ・メンタルケアを設定します。
3. 「7日間をシミュレーション」で週を進め、生活イベントへ対応します。
4. 週次レポートを見て、翌週の計画を修正します。
5. 12週目の大会で採点と講評を確認します。

進行はブラウザの `localStorage` に自動保存されます。ページを再読み込みしても「続きから」で再開できます。

## 実装内容

- ボディビル / メンズフィジークのカテゴリ別採点
- 体重、脂肪、部位別筋量、体調、疲労、怪我リスクの週次変化
- 脚・体幹・握力・フォーム・疲労を使った複合種目品質
- PFC、カロリー収支、食事/トレーニング遵守率
- 性格相性のある5種類のメンタルケア
- 8種類の生活イベントから、1プレイにつき7回発生
- 6種類の筋トレプリセットと詳細調整
- 乱数シード付きセーブ、12週大会、講評、再挑戦
- オフラインキャッシュとWeb App Manifest

主要な調整値・プリセット・イベント・採点項目は `src/game/config.ts`、計算処理は `src/game/engine.ts` に分離しています。
